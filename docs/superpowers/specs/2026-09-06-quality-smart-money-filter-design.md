# 优质筛选与主力动向筛选优化设计

日期：2026-09-06
状态：待用户审阅

## 目标

优化“优质筛选”和“主力动向”两个页面的筛选可解释性与排序稳定性，不新增数据库表，不增加网络调用，并保持现有 API 参数和合规免责声明兼容。

## 一、优质筛选

### 严格主清单

当 `strict_quality=True` 时，`main` 只包含同时满足以下条件的标的：

1. `hard_gate_pass=True`；
2. 数据可信度达到 `min_confidence` 对应的严格门槛；
3. 未触发硬风险门槛；
4. 命中口径数量达到 `min_dims`；
5. 具备可用于排序的有效共振分。

严格模式不使用低可信度、硬门槛失败或风险标记项补足 `limit`。符合数量不足时保留实际结果，并返回明确的不足状态。

### 响应字段

顶层新增：

- `selection_status`：`ok` 或 `insufficient`；
- `eligible_count`：严格合格数量；
- `requested_limit`：请求数量；
- `selection_note`：严格模式下的结果说明；
- `excluded_summary`：按排除原因统计数量。

每个候选项统一保留/补充：

- `eligibility`：是否可进入严格主清单；
- `exclusion_reasons`：硬门槛、可信度、风险、口径不足等原因；
- `confidence_level`、`risk_flags`、`hard_gate_pass`；
- `raw_resonance`、`adjusted_resonance`。

`by_dim` 继续保留诊断项，不能被误解为严格主清单。

### 前端

优质筛选页面增加摘要区：请求数量、严格合格数量、硬门槛排除数量、低可信度数量。主清单标注“严格合格”；数量不足显示醒目的非错误提示。分口径诊断项显示排除原因，而不是只展示分位数。

## 二、主力动向

### 排序原则

- 默认排序优先使用 `net_intensity`（主力净额/当日成交额），降低绝对金额对大市值标的的偏置；
- 保留绝对净额排序作为用户可选项；
- 不把金额通道与股数通道混入同一数值排序；
- 按个股视图提供强度、绝对净额、通道数量、正向通道占比等排序选项；
- 十大股东、高管增减持、限售解禁继续按股数展示并保持单位隔离；
- 对强度高但绝对规模小的结果保留，同时显示覆盖/规模信息，避免强度被误读为规模。

### 前端

主力动向增加排序选择。流水账默认强度排序，仍可切换绝对净额；按个股聚合视图显示金额通道强度与绝对净额、通道数量和方向占比。单位不同的股数通道不参与金额强度比较。

### 后端

优先复用现有 `/api/smart-money/today` 响应中的 `net_intensity` 和现有聚合结果，不新增触网调用。若查询层需要排序参数，新增可选参数并保持默认兼容；非法排序值回退到安全默认值。

## 三、测试与验证

- 优质筛选：严格结果不足不补齐、硬门槛排除、低可信度排除、排除原因统计、非严格模式兼容；
- 主力动向：强度默认排序、绝对净额可选、按个股通道单位隔离、方向/通道统计；
- 运行相关单测和全量测试；
- 浏览器验证两个页面的摘要、筛选器、排序和解释文本；
- 使用部署脚本重建、健康检查和路由冒烟。

## 合规与兼容

所有结果继续使用“机械排序/观察清单/非荐股非买卖信号”措辞。新增字段只扩展响应，不删除现有字段；不改变其他页面行为。
