# quality 共振维度权重 IC 校准研究 — 设计

**日期**：2026-09-30
**性质**：architectural 研究设计。目标是**首次给 quality 共振维度权重**（`backtest/quality.py::_DEFAULT_DIM_WEIGHTS={1:1.0, 2:1.3, 3:0.6, 4:0.7, 5:1.3}`）提供量化依据，替换当前"纯经验先验"。出身：`docs/weights-calibration-transparency-2026-09-30.md` 的建议 1 + 功能盘点 P2 · 3.2（CLAUDE.md quality 节"IC 透明度报告待续"）。
**范围边界**：**只读研究**，产出研究报告 + 权重建议；**不自动改生产权重**。落地与否由用户后续拍板。

---

## 1. 背景与动机

质量五口径的共振权重目前是**经验先验**（源码注释自述"因子有效性先验,非 IC 校准"）：口径2 价值质量 / 口径5 行业景气（高持久）> 口径1 风险调整 > 口径4 多信号 > 口径3 资金流向（最噪声）→ 权重 2、5 最高（1.3）、3 最低（0.6）。

透明度报告已指出这是"全仓最大的凭感觉风险点"，建议"复用 `backtest/research.py` 的 IC/分层流程，对每个口径按可用因子横截分位做 rank-IC，再定权"。

## 2. 关键可行性约束（本设计的诚实基础）

"校准口径权重"需要"每个口径随历史日期的逐日横截分位序列"。但五口径的数据可重建性不同：

| 口径 | 因子来源 | 可否全历史重建 | 校准方式 |
|---|---|---|---|
| 1 风险调整 | close/amount 面板 | ✅ 完全可重建 | 因子级 rank-IC/分层 |
| 4 多信号 | `scan_signals`(OHLCV 触发) + `backtest_signals` 前视胜率 | ✅ 可重建(事件触发式) | 信号触发→前视收益胜率/方向 |
| 2 价值质量 | buffett 财报 | ❌ 仅 7 天 TTL 缓存 + tdx 当前公司信息；akshare 财报接口东财封 | 不可校准 |
| 3 资金流 | `smart_money_action` + 北向 | ❌ 过去逐股北向停更 2024-08、主力序列只向前累积 | 不可校准 |
| 5 行业景气 | research 研报/板块 | ❌ 仅近期研报 | 不可校准 |

**结论**：一次"全五口径 IC 校准"以现有数据**做不到**。本项目交付对**口径1/4 的真实证校准**，对 **口径2/3/5 诚实标注"数据不可历史重建，保留经验先验"**，不臆造校准。

## 3. 方法

### 3.1 口径1（风险调整）—— 全历史连续因子校准

复用 `scripts/quality_diag.py` 已有管线（`backtest.eval` 的 `forward_returns/ic_series/ic_summary/decile_backtest`）：

- 面板：`stock_daily` pivot → `(close, amount, codes)` 横截面（`_load_daily_panels`）
- 因子（滚动、前视安全）：`momentum_20/60`、`volatility_20`(取负，低波动好)、`sortino_20`、`amount_accel`
- 指标：每因子 × `k∈{5,20}` → rank-IC + 胜率 + 5 档多空单调性
- 产出：哪些因子真预测前视收益、方向对不对 → 校验口径1 内部构成 + 给口径1 维权重实证锚点

### 3.2 口径4（多信号）—— 事件触发式校准

口径4 是"事件触发"非连续因子，改用 `signals.backtest_signals` 的历史前视统计：

- 复用 `/api/signals/backtest` 同款：每个触发信号扫历史触发点 t → t+k 收益，得逐信号前视收益/胜率
- 判定：当日触发数 `signal_hits` 越多是否真的越好（触发强度 → 前视收益的单调性）→ 校验口径4 的 `win_rate`/`signal_hits`/`recent_intensity` 三因子该不该按当前权重进共振、方向对不对

### 3.3 口径2/3/5 —— 诚实标注

不造历史、不掺无证据判断；报告中明确记录三条：
- 口径2：无长历史财报缓存，不可校准
- 口径3：过去逐股北向停更 2024-08 + 主力序列只向前累积，原理上不可校准
- 口径5：仅近期研报，不可校准

## 4. 产出物

一份**只读研究报告** `docs/quality-dim-calibration-2026-09-30.md`：

1. 口径1 各因子 rank-IC 表 + 5 档多空（复用 `quality_diag.render_report` 格式）
2. 口径4 各信号触发→前视胜率表 + signal_hits 单调性
3. 每条结论标**"有实证依据" / "经验先验保留"**两类
4. **权重建议**：对可校准维（1/4）给证据支持的方向性调整建议；对不可校准维（2/3/5）明确"维持经验先验" + 理由
5. 局限与免责（机械统计诊断，非买卖信号）

## 5. 落地方式 + 文件

| 文件 | 动作 |
|---|---|
| `scripts/quality_diag.py` | **扩展**：新增口径4 校准段（复用 `backtest_signals` + `eval`），其余保持只读 |
| `docs/quality-dim-calibration-2026-09-30.md` | **新增**：研究报告 |
| `tests/test_quality_diag.py` | **新增/扩展**：口径4 校准段可单测（mock `backtest_signals` 返合成胜率，验证聚合/方向判定），不依赖网络 |

**明确不动**：`backtest/quality.py::_DEFAULT_DIM_WEIGHTS` 生产权重。原因：
- 口径2/3/5 无法校准，全维度重排会掺入无证据判断
- 改默认权重静默改变排序，而 `tracker.is_default_params` 只挡参数不挡权重 → 污染 `list_track` 样本统计（透明度报告第 89 行已警示）

若报告建议 + 用户拍板应用，才走**独立的新一轮** plan → 改动权重 + 同步 cache 键 + 测试 + `list_track` 说明。

## 6. 合规与边界

- 脚本只读库不写库；报告措辞"机械统计诊断/研究优先级/非买卖信号"，不荐股不承诺收益
- 产出是**权重校准研究**，不改变任何排序签名、不新增路由、不新增采集、不触网
- 报告标注数据局限（口径1/4 入选池按当前 `stock_spot` 划分，诊断反映因子本身区分度非全流程点对点）
