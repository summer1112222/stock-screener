## 1. nextday 五因子权重（次日强势主清单）

**值**：`mom_5_1=0.30 / rel_strength=0.20 / sr_10=0.15 / close_vol_corr=0.10 / liq_turnover=0.15`

**来源**：**IC 校准**，2026-09-06，样本 692 只 / 1619 交易日（源码注释 `nextday.py:647-649`）。

**逐因子依据**：
- `mom_5_1`（短中期动量，跳过最近1日隔夜噪声）：**唯一 1 日强正 IC +0.023，胜率 54%** → 由原权重提至 0.30。
- `close_vol_corr`（量价共振）：**双窗口负 IC**（1 日 −0.007 / 5 日 −0.018）→ 由 0.20 大降至 0.10（逆着信号，降低权重）。
- `sr_10`（波动率归一收益）：弱正（1 日 +0.007）、5 日转负 → 降至 0.15。
- `rel_strength`（横截相对强度）/ `liq_turnover`（流动性质量）：**无法用 OHLCV 回测** → 维持经验先验值，无校准依据。

**用途**：次日强势清单 `score`（每因子横截面 rank-pct → 按可用因子重归一加权，`denom` 处理缺失）。

**不确定性/复核点**：强证据仅覆盖 `mom_5_1 / close_vol_corr / sr_10` 三因子；`rel_strength / liq_turnover` 是未校准经验兜底。改权重前应重跑同一 IC 流程核验方向。

## 2. quality 共振维度权重（优质筛选主清单）

**值**：`{1:1.0, 2:1.3, 3:0.6, 4:0.7, 5:1.3}`

**来源**：**经验先验（因子有效性排序，非 IC 校准）**，可被 `weights` / `resonance_mode` 参数覆盖（源码 `quality.py:60-63`）。

**维度语义与排序依据**（源码注释）：
- 口径1 风险调整 / 口径2 价值质量 / 口径3 资金流向（radar 共振，最噪声）/ 口径4 多信号 / 口径5 行业景气（研报）。
- 排序逻辑：**口径2 价值质量 / 口径5 景气（高持久）> 口径1 风险调整 > 口径4 多信号 > 口径3 资金流（最噪声）** → 权重 2、5 最高（1.3），3 最低（0.6）。

**聚合**：`greedy`（命中口径加权均值）或 `penalize`（加权几何均值）；`wsum/wtot` 已处理，权重和不必为 1。

**不确定性/复核点**：纯经验先验，**无本地 IC/分层样本回测依据**。改权重时目前没有量化证据支撑，是全仓最大的"凭感觉"风险点。

## 3. macro_style 宏观风格因子（B1 地基，仅作 B2 调制不改排序）

**值**：`{zt:0.30, margin:0.25, pe:0.25, breadth:0.20}`

**来源**：**经验先验，非 IC 校准**（源码 `_W`；参考轴 `_ZT_REF=50` 涨停 / `_MARGIN_REF=50亿` 两融）。

**语义**：涨停家数（zt，达 50 饱和进攻）/ 两融环比（margin，±50 亿 tanh 饱和）/ PE 分位（pe，低分位→进攻有空间）/ 涨跌家数宽（breadth）。

**用途**：产出 `score∈[-1,1]` + `style∈{attack/neutral/defense}`，供 B2 调制 `sector_heat` 政策命中加成；**自身不改任何排序签名**。

**不确定性/复核点**：经验阈值，未校准；`score` 只作相对风格基调，不直接进排序键，风险较低。

## 建议（后续可选）

1. **若要对 quality 共振权重做校准**：复用 `backtest/research.py` 的 IC/分层流程，对每个口径按可用因子横截分位做 rank-IC，再定权（替换当前经验先验）。
